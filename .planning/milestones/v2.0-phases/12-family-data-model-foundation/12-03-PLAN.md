    `export async function linkParent(childId, { motherId, fatherId } = {})`: if `motherId != null`,

    an `updates` object containing only the keys that were actually passed (`motherId !== undefined`
    / `fatherId !== undefined`, so omitted keys are left untouched rather than nulled), and call

    constraint reject a nonexistent parent id — no separate existence pre-check needed). Implement
