UI-SPEC.md node anatomy contract (exact, load-bearing):
- Node: `180x64px` card, white surface, `1px solid colors.line` border, theme `borderRadius`. Left-to-right/top-to-bottom: `MemberAvatarImage` -> full name (14px/600) -> birth-death years line (12px/400, muted `colors.slate`, format `1932–2001` / `1932–` / `–2001` / omitted if both unknown) -> gender indicator (icon + tint, never color-only).
- Gender icons from `@mui/icons-material`: `MaleRounded` (blue tint, `aria-label="Male"`), `FemaleRounded` (rose tint, `aria-label="Female"`), `TransgenderRounded` (`colors.slate` tint, `aria-label="Other"`).
- Viewer's own node: `2px solid colors.primary` ring + outlineOffset 2px + a small "You" chip (D-09a) — not color-only. The ring is a structural style keyed on `data.isViewer`, distinct from and in addition to the chip — both must render.
- Focus-visible: `2px solid colors.primary` outline, `outlineOffset: 2px` (matches MemberCard.jsx focus pattern).
- Collapsible node with hidden children: count-badge affordance near the BOTTOM of the card, e.g. `+3`, `aria-label="Show 3 hidden descendants of {name}"` (expand) / `"Hide descendants of {name}"` (collapse).
- Collapsible node with a hidden parent (D-03, e.g. a spouse's own separate mother/father not on the viewer's spine): a symmetric count-badge affordance positioned near the TOP of the card (ancestors render above in the TB layout), e.g. `+1`/`+2`, `aria-label="Show {N} hidden ancestors of {name}"` (expand, N = 1 or 2 depending on how many of mother/father are currently hidden) / `"Hide ancestors of {name}"` (collapse). This badge is visually and semantically distinct from the descendant badge (different position, different aria-label direction, independent visibility condition) — this is the discoverable path to D-03's "collapsed/hidden behind an expander" disconnected apex roots, not auto-expansion, not the search box alone.
- Touch targets ≥44x44px on all interactive controls (find-me, zoom, expand toggles, node click surface).
- Controls sit in an xyflow `<Panel>` cluster, white secondary surface, inset `24px` (lg) from canvas edge.
