| Boundary | Description |
|----------|--------------|
| Unauthenticated browser reaching `/verify-email` | Must be reachable without a session (it's how a session is FIRST established for a new account) — the route must sit outside `ProtectedRoute` |
| `sequelize.sync()` vs. a real, already-provisioned dev/prod database | Schema changes to a live database are outside the ORM's control this milestone — this is the last plan in the phase, so it's also the last chance to catch a schema-drift regression before the phase is considered done |

| Threat ID | Category | Component | Disposition | Mitigation Plan |
