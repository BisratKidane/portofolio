<objective>
Write the portable manual migration `018-add-family-members-geez-names.sql` (three nullable `utf8mb4` columns on `family_members`, per D-03's bare-portable-DDL requirement), prove its cross-engine portability by applying it against a real local MariaDB instance in an isolated scratch database (not the project's own dev/test DB), and document it in README's manual-migration list per D-03 (portability note) and D-04 (prod-apply-deferred note).

Purpose: `sequelize.sync()` never alters existing tables (Pitfall 2), so this hand-written `.sql` file is the only way any already-provisioned database gets the new columns. This app straddles two engines — MariaDB locally, MySQL 8.4 in prod — so the DDL must avoid MySQL-8-only tokens (`utf8mb4_0900_ai_ci` collation, `ENCRYPTION=`) that break MariaDB (D-03, Pitfall 3). Per D-04, this migration is NOT applied to the live prod DB in this phase.
Output: `018-add-family-members-geez-names.sql` committed and proven to apply cleanly on local MariaDB; README documents it; no project database (dev, test, or prod) is left mutated by the verification step.
</objective>
