<objective>
Make the three writable Ge'ez name fields (`geezFirstname`, `geezLastname`, `geezMothersname`) and the read-only derived `geezFullname` flow through the existing GraphQL API using the existing spread-passthrough create/update resolvers, with zero new resolver logic (DATA-03). Purpose: Opens the API surface to the Ge'ez columns Phase 18 added to the model, so Phases 22 (read) and 23 (write) can render/edit them. This is a backend-only, extend-existing phase — pure pattern-continuation of in-file analogs (`fullname`, `mothersname`).

Output: Updated schema SDL, extended `OPTIONAL_FAMILY_MEMBER_FIELDS`, hardened VIRTUAL declaration, and a focused GraphQL integration test proving the round-trip and the clear-to-null (SC3) behavior.
</objective>
