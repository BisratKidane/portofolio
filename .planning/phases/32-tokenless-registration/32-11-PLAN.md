| Boundary | Description |
|----------|--------------|
| Anonymous internet caller -> `verifyEmail`/`resendVerificationEmail` | Unauthenticated GraphQL mutations; anyone holding a token (legitimately issued or otherwise reissued) can call these. |
| Admin caller -> `updateUser` (editing another account) | An authenticated ADMIN may edit any other account's name/email/role; the security boundary is which accounts remain reachable for that edit at all. |
