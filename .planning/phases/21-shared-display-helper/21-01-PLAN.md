<objective>
Create a single shared, unit-tested pure-function helper, `getGeezDisplay(member)`, in a new `frontend/src/utils/` directory. It reads the already-server-derived `member.geezFullname` field and returns `null` when absent or `{ text, lang: 'ti' }` when present. This is the ONE place the Latin/Ge'ez precedence and empty-handling rule lives, so Phase 22's render surfaces (MemberNode, MemberCard, AdminMemberTable, etc.) can all call the same helper instead of re-deriving the rule independently and drifting apart (VIEW-03, and the helper half of QUAL-01).

Purpose: Prevent per-component drift in how "does this member have a Ge'ez name" is decided and rendered, before any consumer is wired (Phase 22).
Output: `frontend/src/utils/displayName.js` (implementation) + `frontend/src/utils/displayName.test.js` (RED-then-GREEN unit tests, none/partial/all-filled + null-vs-empty-string proof).
</objective>

<locked_decisions>
1. Return shape: `null | { text: string, lang: 'ti' }`. Mirrors `formatDate()`'s null-or-value idiom in `frontend/src/components/family/MemberNode.jsx` (lines 24-29), enabling `{geez && <Typography lang={geez.lang}>{geez.text}</Typography>}` at future call sites with no unwrapping.
2. Data source: reads `member.geezFullname` ONLY (Phase 18's defensive VIRTUAL getter, exposed via Phase 19's GraphQL layer — joins first+last, excludes mothersname, null when absent). MUST NOT recompute a join from `geezFirstname`/`geezLastname` — that would relocate the exact drift bug this phase exists to prevent.
3. `lang` is a hardcoded constant `'ti'` (Tigrinya) — exported as `GEEZ_LANG`, not a function parameter. No `dir` attribute anywhere (Ge'ez/Ethiopic script is LTR).
4. The helper owns ONLY the Ge'ez half. It does not return, read, or touch `member.fullname` — every consumer keeps rendering the Latin name unconditionally and unchanged (VIEW-01, out of this phase's scope).
5. Scope guard: this phase creates ONLY `frontend/src/utils/displayName.js` + its colocated test. It does NOT modify any consumer file (MemberNode.jsx, FamilyTreeCanvas.jsx, MemberCard.jsx, AdminMemberTable.jsx, etc.) — that retrofitting is Phase 22. `MemberDetailPanel.jsx` is entirely OUT of v3.0 scope — do not reference it as a future consumer.
6. Export name: `getGeezDisplay` (RESEARCH.md A1 recommendation). This is the public API Phase 22 imports.
7. Test contract (SC3): the absent case must be provably distinct from empty string. Assert `toBeNull()` for absent AND a separate `.not.toBe('')` assertion. Cover none (geezFullname null/undefined/''/whitespace-only → null), partial (single Ge'ez part already joined into geezFullname → { text: '<part>', lang: 'ti' }), all-filled (both parts joined → { text: '<first> <last>', lang: 'ti' }). Use real Ethiopic fixtures reused from Phase 18/20 (firstname 'ጃነ', lastname 'ዶ', geezFullname 'ጃነ ዶ').
</locked_decisions>
