- D-04: Results capped (~20) and sorted `lastname ASC, firstname ASC` — no relevance ranking in the backend.

| Boundary | Description |

| Client → GraphQL API | Untrusted `term`/`limit` arguments cross into `searchFamilyMembers`; the caller's JWT-derived identity (`context.user`) crosses into both new queries' authorization gate |
| API → Database | `getFamilyHeadId`'s one raw `sequelize.query` executes a fixed CTE string with zero user-supplied arguments; `searchFamilyMembers` builds a parameterized `Op.substring` where clause from user input |
