const PUBLIC_REGISTRATION_SETTING_QUERY = `
  query PublicRegistrationSetting {
    publicRegistrationSetting {
      enabled
      updatedAt
      updatedByName
    }
  }
`;
const SET_PUBLIC_REGISTRATION = `mutation SetPublicRegistration($enabled: Boolean!) { setPublicRegistrationEnabled(enabled: $enabled) { enabled updatedAt updatedByName } }`;

Payload semantics (all three D-06 attribution variants):
  { enabled, updatedAt: null,  updatedByName: null }   -> "Not changed since setup."
  { enabled, updatedAt: "<epoch-ms string>", updatedByName: null }   -> "Opened/Closed by an administrator on {date}."
  { enabled, updatedAt: "<epoch-ms string>", updatedByName: "Bisrat" } -> "Opened/Closed by Bisrat on {date}."

From frontend/src/api/graphqlClient.js (existing, unchanged):
  graphqlRequest(query, variables = {}) -> Promise<data>   // flattens GraphQL errors to new Error(messages.join('\n'))

From frontend/src/theme.js (existing — do not add tokens):
  colors.primaryDark  (OPEN icon)   colors.slate  (CLOSED icon)   colors.line  (Paper border, Divider)

Every string below is verbatim from 34-UI-SPEC.md § Copywriting Contract. Do not paraphrase.

Region title (h4): `Public signup`
Region description (body1, text.secondary — STATIC, state-independent): `Whether someone without an invitation can create an account. Closing it stops new requests — it doesn't affect invitations you've already sent, or anyone already waiting in the queue below.`
State headline OPEN (h6): `Public signup is open`
State headline CLOSED (h6): `Public signup is closed`
Attribution, named actor: `Opened by {name} on {date}.` / `Closed by {name} on {date}.`
Attribution, unknown actor: `Opened by an administrator on {date}.` / `Closed by an administrator on {date}.`
Attribution, never changed: `Not changed since setup.`
Switch tooltip OPEN: `Open — click to close public signup`
Switch tooltip CLOSED: `Closed — click to open public signup`
Switch accessible name: inputProps={{ 'aria-label': 'Public signup' }}
In-flight line: `Closing public signup…` / `Opening public signup…`
Loading line: `Checking whether public signup is open…`
Load-failure button: `Retry`
Dialog title: `Open public signup?`
Dialog body (body2, text.secondary): `Anyone who reaches the sign-up page will be able to create an account without an invitation. Every request still needs your approval before it becomes active, and you can close this again at any time.`
Dialog escape hatch (plain Button): `Keep it closed`
Dialog confirm (Button variant="contained", default primary — NOT color="error"): `Open signup`, and `Opening…` while the mutation is in flight.
