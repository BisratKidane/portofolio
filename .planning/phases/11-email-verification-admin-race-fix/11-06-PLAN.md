| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-11-06a | Elevation of Privilege (client-side half) | `AuthContext.register` | mitigate | `register` is fully decoupled from `authenticate()` and can never write `localStorage`/`setUser`, proven by Test 1 asserting no session artifacts exist after a successful call — matches the backend's message-only contract (Plan 11-04) so there's no client-side path to a false "logged in" state for an unverified account. |
