Output: `@fontsource/noto-sans-ethiopic@^5.3.0` installed in the frontend workspace; two Ethiopic-subset CSS side-effect imports in `main.jsx`; updated `FONT_SANS`/`FONT_DISPLAY` constants in `theme.js`; a new `theme.test.js` proving the font-stack ordering automatically.
