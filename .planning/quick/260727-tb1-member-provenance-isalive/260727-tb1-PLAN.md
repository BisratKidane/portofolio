# Member provenance + isAlive

## Goal (TDD)
1. Track provenance on family members: **who added** + **when**, **who last changed** + **when**.
2. Replace the **deathdate** field with **isAlive** (boolean) across API + UI.
3. Give admins a **button to toggle isAlive** (in /manage list AND the /family detail panel).

## Decisions (from user)
- History depth: **last editor + creator** (createdByUserId, updatedByUserId + createdAt/updatedAt) — no audit-log table.
- Death dates: **keep the deathdate column in the DB (hidden/unused)**; backfill isAlive from it; app reads/writes isAlive only.
- Toggle location: **both** /manage list and /family detail panel.
- Provenance visibility: **admins only**.

## Backend
- Model `FamilyMember`: add `isAlive BOOLEAN NOT NULL DEFAULT true`. Keep `deathdate` column.
- Associations: `FamilyMember.belongsTo(User, as createdByUser / updatedByUser)` (FKs
  `createdByUserId` / `updatedByUserId`, `ON DELETE SET NULL`).
- Loader: add `userById` for batching provenance lookups.
- Schema: FamilyMember gains `isAlive: Boolean!`, `createdBy: User`, `updatedBy: User`,
  `createdAt`, `updatedAt`; **remove** `deathdate` from type + both inputs; add `isAlive` to
  `NewFamilyMemberInput` + `EditFamilyMemberInput`.
- Resolvers: stamp `createdByUserId` on every create site (addParent/addSpouse/addChild/
  addSibling + linkUserToMember); stamp `updatedByUserId` on editMember. `createdBy`/`updatedBy`
  field resolvers return the user **only for ADMIN**, else null (mirrors linkedUser gating).
- Migration (prod): add columns + FKs, backfill `isAlive = (deathdate IS NULL)`.

## Frontend
- `MemberFields`: replace the Deathdate DatePicker with a **Living** switch (isAlive).
- `AddRelativeDialog` / `EditMemberDialog`: form + mutation field lists deathdate → isAlive.
- `MemberNode`: `showAddress` keyed off `isAlive`.
- `MemberDetailPanel`: show Living/Deceased; admin-only **toggle** (calls editMember via parent).
- `FamilyTreePage`: query deathdate → isAlive; wire toggle handler + refetch.
- `ManagePage` / `AdminMemberTable`: deathdate → isAlive; admin **toggle** in the list; show
  **Added by / Updated by** provenance (admins only).

## Must-haves
- Every member create records the acting user; editMember records the last editor.
- Provenance only ever visible to admins (createdBy/updatedBy null otherwise).
- Death dates preserved in DB (column kept), app fully switched to isAlive.
- Admin can flip isAlive from both surfaces; full suites green.
