# Quick Task 260726-wn2: Agne rebrand

Frontend-only branding pass. Theme palette: gradient `#6366f1→#a855f7`, male tint
`#3b82f6`, female tint `#ec4899`, slate `#64748b` (theme.js).

## Tasks

1. **Family-tree logo (theme-colored) + favicon.**
   - `frontend/public/favicon.svg` — self-contained: rounded tile filled with the
     app gradient + a white tree-of-people glyph. Link it in `index.html`
     (`<link rel="icon" type="image/svg+xml" href="/favicon.svg">`).
   - `BrandMark.jsx` — replace the gradient "P" glyph with the white tree glyph on
     the same gradient tile (reuse across navbar + auth cards).

2. **Gender default avatars.**
   - New `frontend/src/components/MemberFallbackAvatar.jsx` — SVG avatar by gender:
     Male = blue `#3b82f6` bg + white figure + glasses; Female = pink `#ec4899` bg +
     white figure + long hair; other/unknown = slate `#64748b` bg + plain figure.
     Fills 100% of its box, `aria-hidden` (decorative — gender is already in the
     node's aria-label), `data-testid="member-fallback-avatar"`, `data-gender`.
   - `MemberAvatarImage.jsx` — when there's no photo (and on blob-fetch failure),
     render `MemberFallbackAvatar` for the member's gender instead of the generic
     PersonRoundedIcon, respecting the existing `size`/`fill`/`variant` shape.

3. **Rename Portofolio → Agne (user-facing only).**
   - `index.html` `<title>`, `BrandMark` text, `Login.jsx` (×2), `Register.jsx` (×1).
   - Do NOT touch package names, DB name (`portofolio`), or repo/internal ids.

4. **Tests.**

     PersonRoundedIcon). Keep the MemberNode gender test green — the fallback must
     NOT expose `svg[aria-label="Male"/"Female"]` (it's aria-hidden with `data-gender`).
   - Full `npm test --workspace frontend -- --run` green.
